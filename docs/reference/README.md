# Referencias do produto

Este diretorio torna as decisoes de produto relevantes acessiveis sem dependencia de caminhos
externos ao repositorio.

- [product-requirements.md](product-requirements.md): requisitos funcionais e tecnicos aprovados.
- [visual-language.md](visual-language.md): resumo versionado da linguagem visual dos mockups.

Os arquivos visuais binarios originais nao sao necessarios para executar o primeiro incremento.
Quando o desenvolvimento da interface for iniciado, as imagens aprovadas deverao ser importadas
para este repositorio com seus hashes de origem.
